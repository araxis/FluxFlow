## Open hardware check

**BLE GATT Server on Windows.** On the tested Qualcomm adapter, Windows still reported `Started` after Stop on .NET 8 and 10. A native-only process reproduced that status. Whether the adapter continued advertising is unresolved. When an independent BLE scanner is available, record fresh advertisements for the test service before Stop, during a timed scan after Stop, and after the next Start. Record the Windows status and start outcome alongside those observations. [Hardware findings](../../Code/eng/ble-companion-proof/README.md)

**Deployment-specific coverage.** ROS native coverage applies to Linux Jazzy on localhost. Windows-native ROS would need its own trial if selected for deployment. Serial partial-write and disconnect coverage uses a controlled port. Adapter-specific close timing can be checked on the deployment hardware. [ROS platform scope](2026-11-16-ros2-string-readiness.md), [Serial trials](../../Code/tests/Unit/FluxFlow.Components.Serial.Tests/SerialSessionTests.cs)
