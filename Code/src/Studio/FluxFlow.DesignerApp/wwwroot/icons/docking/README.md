# Docking icons

Unmodified [Microsoft Codicons](https://github.com/microsoft/vscode-codicons) SVGs from `src/icons`, used for the docking guide's pane targets. Copyright Microsoft Corporation. Licensed under [CC BY 4.0](LICENSE).

The guide uses `layout-sidebar-left`, `layout-sidebar-right`, `layout-menubar` (top), `layout-panel` (bottom) and `layout-centered` (tab group). Color and size follow the shared Studio theme.
