# FluxFlow.Components.RabbitMQ

AMQP publishing, consumption and correlated delivery acknowledgement.

This library contains the runtime components and depends on
`FluxFlow.Plugins.RabbitMQ.Settings` for settings and validation.
The complete RabbitMQ plugin adds registration, portable editors and documentation
for Studio. This runtime package has no dependency on a UI framework.

Targets .NET 8 and .NET 10.
