# FluxFlow.Plugins.RabbitMQ.Settings

Shared connection, broker declaration and acknowledgement settings for RabbitMQ runtime and portable editors.

This library supplies the settings contracts and validation used by the RabbitMQ
plugin. It has no dependency on a UI framework and does not open network connections.
Use the complete plugin to install the components and their editors in Studio.

Targets .NET 8 and .NET 10.
