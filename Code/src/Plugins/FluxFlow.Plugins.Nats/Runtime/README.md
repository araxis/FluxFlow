# FluxFlow.Components.Nats

NATS and JetStream publishing, consumption, request/reply and explicit settlement.

This library contains the runtime components and depends on
`FluxFlow.Plugins.Nats.Settings` for settings and validation.
The complete Nats plugin adds registration, portable editors and documentation
for Studio. This runtime package has no dependency on a UI framework.

Targets .NET 8 and .NET 10.
